# PrefQuest Study 2 — 实验员 Session SOP

**版本**：2.5（2026-04-25）  
**适用对象**：主实验员（PI）及助手实验员  
**实验设计**：被试内设计，3 种策略条件（TO / UL / LL），每人 3 个 trial  
**预计时长**：每次 session 约 65–75 分钟

> **问卷测量分层**：TE / PTU / PQE 为 **primary**（对应 RQ3c 体验维度与主客观解离假设，进入 Friedman + Wilcoxon post-hoc 假设检验）；Session-end 比较问卷（S1 排序 + S2–S6 维度选择 + S7 操纵检验）作为 **behavioral outcome**（策略整体偏好与维度偏好的非参数分析）。每个 trial 共 10 题（TE 3 + PTU 3 + PQE 4），约 3 分钟；Session-end 问卷约 5 分钟。

**角色分工**

| 角色 | 职责 |
|---|---|
| **主实验员（PI）** | 接待参与者、主导口头介绍、主导退出访谈、处理突发情况、负责数据导出 |
| **助手实验员** | 操作实验员控制面板、控制 STT 录音、推进 Phase、做访谈笔记 |

> Phase 2 对话期间：助手专注操作屏幕，主实验员坐在参与者旁边观察，**不干预对话内容**。

---

## 一、实验前

### 1.1 设备清单

- [ ] 实验员电脑（运行 study2_app 后端 + 前端）
- [ ] 实验员显示器（实验员控制面板，参与者不可见）
- [ ] 平板 / iPad（偏好表单 + 问卷，充满电）
- [ ] 机器人（TTS 音箱 + 机械臂，已完成调试）
- [ ] 录音设备（退出访谈录音，测试可用）
- [ ] 物理场景道具（各场景物品 + 容器标签；件数见 Appendix B：书桌 24 件 / 吧台 26 件 / 冰箱 24 件）
- [ ] 知情同意书（纸质，含录音授权条款）
- [ ] 参与者编号对照表（已打印，含 Latin Square 分配）

### 1.2 系统启动

```bash
# 1. 激活 conda 环境
conda activate behavior

# 2. 配置 LLM 后端
export LLM_BACKEND=openai
export LLM_MODEL=gpt-5-chat
export LLM_API_KEY=YOUR_KEY
export LLM_BASE_URL=https://your-endpoint/v1

# 3. 启动后端
cd AskThenRearrange/study2_app/backend
python main.py

# 4. 启动前端（另开终端）
cd AskThenRearrange/study2_app/frontend
npm run dev

# 5. 浏览器打开实验员控制面板
# http://localhost:5173/experimenter
```

### 1.3 系统自检（参与者到达前 10 分钟）

- [ ] TTS 测试：点击控制面板测试按钮，确认机器人正常发声，音量适中
- [ ] STT 测试：按住录音按钮说一句话，松开后确认转录文字正确显示
- [ ] 平板测试：打开偏好表单页面，确认拖放功能正常
- [ ] 确认当前参与者的 Latin Square 行号，核对 Trial 1/2/3 的策略和场景顺序
- [ ] 将练习场景道具摆放就绪

### 1.4 参与者接待与知情同意

1. 引导参与者就座，简要介绍实验环境
2. 请参与者阅读知情同意书并签字（含录音授权）
3. 将平板递给参与者，填写**人口统计学问卷**（年龄、性别、整理频率、机器人使用经验单题）（约 5 分钟）
4. 回收平板

### 1.5 口头介绍（逐字稿）

> "感谢参与本研究。今天你会体验一个家居整理机器人，它会通过提问来了解你的整理习惯。你只需要用正常说话的方式回答机器人的问题就可以了。
>
> 每轮实验开始时，你会看到一个场景里的物品和可以放置它们的容器。然后机器人会向你提问，你口头回答。机器人会根据这段对话，对场景里**所有物品**做出整理预测——包括它没有直接问过你的物品。当你觉得机器人已经足够了解你的整理方式了，直接告诉我'可以结束了'，我来操作结束这个对话。
>
> 对话结束后，你需要在平板上为每件物品选择你最希望它被放置的容器，再完成一个简短的问卷。最后我们会一起看看机器人的预测结果。整个过程大约需要 65 分钟。
>
> 在正式开始前，我们先用一个练习场景熟悉一下流程。有任何问题都可以随时问我。"

**注意**：全程不提及"策略"或"条件"，不告知参与者存在三种不同的提问方式。

### 1.6 练习 Trial

**场景**：练习场景（不纳入分析）｜**策略**：TO（固定）

1. 在控制面板选择 **Practice Trial**，策略选 TO，点击 **Start Scene**
2. 摆好练习场景道具，将平板递给参与者（显示物品网格）
3. 按照正式 trial 的完整流程走一遍 Phase 1–4（步骤见第二节）；**注意**：练习阶段不填写任何问卷
4. 练习结束后主实验员口头询问参与者：**"整个流程清楚了吗？有什么问题吗？"**

**练习阶段常见问题回答**：

| 参与者问题 | 实验员回答 |
|---|---|
| "我应该怎么回答？" | "按照你平时的整理习惯回答就好，没有标准答案。" |
| "我能反悔或者纠正吗？" | "可以，在对话阶段直接告诉机器人你想修改就好。" |
| "需要回答多详细？" | "你觉得合适就好，可以简单也可以详细。" |

## 二、实验中

以下操作针对**每一个正式 trial**（共 3 个），按 Phase 顺序执行。

### Phase 1：场景展示（约 3 分钟）

**助手操作**：
1. 在控制面板选择当前 trial（Trial 1/2/3），确认策略和场景已按 Latin Square 填入
2. 点击 **Start Scene**

**主实验员操作**：
1. 将当前场景的物理道具摆放在桌面上
2. 将平板递给参与者（显示当前场景全部物品网格）
3. 对参与者说：
   > "请先看一下桌上的物品和标有名字的容器，同时参考平板上的清单。熟悉之后告诉我准备好了。"
4. 参与者说准备好后：收回平板，助手点击 **Advance to Dialogue**

---

### Phase 2：对话（时长不定，参与者自主控制）

> ⚠️ **本阶段参与者不看屏幕，只与机器人交互。**

**每轮（turn）操作循环**（助手执行）：

1. 点击 **Generate Question** → 机器人自动播放 TTS 问题
2. 等待机器人说完，参与者开始口头回答
3. **按住 STT 录音按钮**，录制参与者完整回答；听到回答结束后松开
4. 系统返回转录文字，显示在文本框中
5. 如有明显转录错误，快速手动修正（**不得改动语义，只修正识别错误**）
6. 点击 **Submit Answer**
7. 侧边栏自动更新当前 PSR@k（仅实验员可见，**不告知参与者**）
8. 重复以上步骤，直到参与者主动表示结束

**参与者说"可以结束了"（或类似表达）时**（助手执行）：
- 点击 **End Dialogue** → 系统触发 Final Placement Planner，自动记录 turn_count

**注意事项**：
- 不主动暗示参与者"还可以继续"或"可以结束了"——让参与者完全自主决定
- 若 TTS 播放失败：助手口头朗读屏幕上的问题原文，继续录音流程
- 若 STT 严重失误（3 处以上实质错误）：告知参与者"我帮你重新录一下可以吗？"，重新录音后替换

---

### Phase 3：偏好表单（约 5 分钟）

**助手操作**：点击 **Advance to Preference Form**

**主实验员操作**：
1. 将平板递给参与者（显示偏好表单）
2. 对参与者说：
   > "请在平板上为每一件物品选择你最希望它被放置的容器。不需要考虑机器人刚才的问题，按照你自己真实的整理习惯来填写。所有物品都选完之后才能提交。"
3. 参与者提交后收回平板

---

### Phase 4：问卷（约 5 分钟）

**助手操作**：点击 **Advance to Questionnaire**

**主实验员操作**：
1. 将平板递给参与者
2. 对参与者说：
   > "请完成这份关于刚才对话体验的问卷，根据你的真实感受作答就好。"
3. 参与者提交后收回平板

> ⚠️ **此时绝对不展示系统预测结果。** 问卷的有效性依赖于参与者对准确率"完全不知情"。

#### 问卷题目（供实验员核对；平板上自动呈现）

所有题目统一使用 **7-point Likert 量表**：1 = 强烈不同意，7 = 完全同意

---

**Part A：教学负担（TE，Teaching Effort）**

| 题号 | 中文 | 英文原文 |
|---|---|---|
| TE1 | 我需要认真思考才能回答机器人的问题。 | I had to think carefully to answer the robot's questions. |
| TE2 | 在这次交互中，表达我的整理偏好需要花费努力。 | It took effort to express my organization preferences in this interaction. |
| TE3 | 在这次交互中，教机器人理解我的偏好让我觉得有心理负担。 | Teaching the robot my preferences in this interaction felt mentally demanding. |

---

**Part B：感知可迁移理解（PTU，Perceived Transferable Understanding）**

| 题号 | 中文 | 英文原文 |
|---|---|---|
| PTU1 | 机器人理解了我的整体整理偏好。 | The robot understood my overall organization preferences. |
| PTU2 | 机器人似乎学到了我放置物体背后的逻辑，而不只是单个物体的位置。 | The robot seemed to learn the logic behind my placements, not just individual object locations. |
| PTU3 | 我相信机器人能把学到的偏好应用到它没有直接问过的类似物体上。 | I believe the robot could apply what it learned to similar objects it did not directly ask about. |

---

**Part C：主动提问体验（PQE，Proactive Questioning Experience）**

| 题号 | 中文 | 英文原文 |
|---|---|---|
| PQE1 | 机器人的问题帮助我表达了自己的整理偏好。 | The robot's questions helped me communicate my organization preferences. |
| PQE2 | 机器人主动决定下一步问什么的程度是合适的。 | The degree to which the robot proactively decided what to ask next was appropriate. |
| PQE3 | 我对机器人决定下一步问什么感到舒适。 | I felt comfortable with the robot deciding what to ask next. |
| PQE4 | 机器人的问题没有显得在过度猜测我的偏好。 | The robot's questions did not seem to be making excessive guesses about my preferences. |

> **分析注记（PQE4 编码方向）**：PQE4 采用否定措辞，但高分（7 = 完全同意"没有过度猜测"）已代表正面体验，与 PQE1–3 方向一致（高分 = 更好的提问体验）。**PQE4 无需反向编码**，可直接纳入 PQE 总分或 EFA。

---

### Phase 5：系统预测展示（约 2 分钟）

**助手操作**：点击 **Show Prediction**（屏幕显示系统预测 vs 参与者偏好对比）

**主实验员操作**：
1. 将屏幕转向参与者
2. 对参与者说：
   > "这是机器人根据你刚才的回答，对每件物品的放置预测。绿色是和你填的一致的，红色是不一致的。"
3. 给参与者 1–2 分钟浏览；可以简单回应反应，**不展开讨论**（讨论留到退出访谈）

**Phase 5 结束后**：
- Trial 1 / Trial 2 结束：助手点击 **Next Trial**，进入 trial 间隔（见 2.6 节）
- Trial 3 结束：进入退出访谈（见第三节）

---

### 2.6 Trial 间隔（约 3 分钟）

**主实验员**：对参与者说 > "我来换一下场景，你休息一下，大约 3 分钟。"

**助手同时**：
- [ ] 撤去旧场景道具，摆出下一个场景道具
- [ ] 在控制面板配置下一 trial 的场景信息（策略 + 场景名）
- [ ] 确认策略与 Latin Square 一致

---

### 突发情况处理

| 情况 | 处理方式 |
|---|---|
| **机器人 TTS 失败** | 助手口头朗读屏幕上的问题原文，继续录音流程 |
| **STT 严重失误（3+ 处实质错误）** | 告知参与者重新录音，替换转录文字 |
| **参与者长时间沉默（>20 秒）** | 主实验员轻声提示："可以用你平时会怎么做来回答，不用太正式。" |
| **参与者想修改之前的回答** | 在当前 turn 文本框末尾追加补充说明后提交，例如："（补充：之前说的书放书架，我更希望放桌面。）" |
| **后端崩溃 / 系统报错** | 记录当前 turn_index，重启后端，从 session 恢复页面继续 |
| **参与者问"机器人表现好不好"** | "我们在问卷之后会给你看结果，先把问卷填完。"（Phase 5 前不透露） |
| **参与者中途退出** | 立即停止录音，导出当前数据，标注为 incomplete，不纳入分析 |

## 三、实验后

### 3.1 Session-end 比较问卷

> ⚠️ **实验员操作前必读**：查阅 Appendix A 中本参与者所在 Latin Square 行，确认三个 trial 的策略顺序，然后将对应标签写在实验记录表上：  
> - **方式A** = Trial 1 的策略（\_\_\_）  
> - **方式B** = Trial 2 的策略（\_\_\_）  
> - **方式C** = Trial 3 的策略（\_\_\_）  
> 参与者全程只看到"方式A/B/C"，不知道策略名称；实验员自行保存映射关系用于后续分析。

**助手操作**：点击 **Advance to Final Questionnaire**，将平板递给参与者

**主实验员**：
> "三个场景都完成了。现在请回顾一下你体验过的三种对话方式——就是你刚才依次经历的方式A、方式B、方式C——完成最后一份问卷。没有对错，按你的真实感受来。"

参与者填写以下内容（平板自动呈现）：

**1. 整体偏好排序**  
请将三种交互方式按喜欢程度排序（最喜欢 → 最不喜欢）：方式A / 方式B / 方式C

**2. 维度偏好选择**（每题选 方式A / 方式B / 方式C 其中一个）

| 题号 | 中文题目 | 英文原文 |
|---|---|---|
| S2 | 哪种方式最能帮助机器人理解你的偏好？ | Which style best helped the robot understand your preferences? |
| S3 | 哪种方式对你来说最省力？ | Which style required the least effort from you? |
| S4 | 哪种方式最适合作为主动家用机器人的提问方式？ | Which style felt most appropriate for a proactive household robot? |
| S5 | 如果在真实家中使用，你最愿意使用哪种方式？ | Which style would you prefer to use at home? |
| S6 | 哪种方式最可能对你的偏好做出错误假设？ | Which style felt most likely to make wrong assumptions about your preferences? |

**3. 操纵检验（S7，开放题，必填）**

> 你注意到三次对话中机器人的提问方式有什么不同吗？请用自己的话描述你观察到的差异。

> ⚠️ **实验员注意**：此题回答用于两个目的：(a) 作为参与者感知到策略差异的质性证据（操纵检验）；(b) 检查盲法是否被破——若参与者回答中出现"TO / UL / LL"或"任务型 / 用户主导 / 学习者主导"等术语，须在实验记录表中标注并报告。

- 参与者提交 S7 后，点击 **S8 Optional Comment** 让参与者填写补充意见（可选）
- 助手点击 **End Session**，系统保存数据

### 3.2 退出访谈（约 12–15 分钟）

**开启录音设备**（再次口头确认参与者同意录音）。主实验员主导，助手做笔记。  
目标：**解释**用户的量表评分，获取不同策略如何影响偏好表达的质性证据。

---

**Section A. 整体比较**

1. 三种交互方式中，你最喜欢哪一种？为什么？
2. 你最不喜欢哪一种？为什么？
3. 你觉得哪一种最适合未来真实家用机器人？为什么？
4. 你觉得哪一种最像自然的人机协作？哪一种最不像？

---

**Section B. 教学负担（对应 TE）**

1. 哪一种方式让你最费脑？为什么？
2. 哪一种方式最容易回答？为什么？
3. 有没有哪类问题让你觉得重复、抽象、难以回答，或者需要想很久？

---

**Section C. 感知可迁移理解（对应 PTU）**

1. 哪一种方式最让你觉得机器人理解了你的整理逻辑？为什么？
2. 有没有哪一种方式让你觉得机器人只是记住了几个物体的位置？
3. 你觉得机器人有没有学到可以迁移到新物体的规则？哪种方式下最明显？
4. 当机器人没有直接问某些物体时，你对它正确放置那些物体有多大信心？是什么让你这么想？

---

**Section D. 主动提问体验（对应 PQE）**

1. 你觉得机器人主动决定下一步问什么，这件事自然吗？
2. 哪一种方式下，机器人的主动性最合适？
3. 有没有哪一种方式让你觉得机器人问得太多、太少、太具体或太抽象？

---

**Section E. 策略专项探针**

> ⚠️ **实验员注意**：以下各策略探针，提问时一律用"方式A/B/C"称呼，不得说出"TO""UL""LL"等策略名称。根据当前参与者的 Latin Square 行号，确认 方式A/B/C 分别对应哪种策略后，选择对应探针提问。

> **引导题**（在参与者自发描述完 A–D 之后再问）：  
> "回顾一下这三次对话——逐个询问物体位置、直接表达整理规则、确认机器人提出的规则——这三种方式哪种对你来说最自然？"  
> （此题在参与者已自由表达体验后提问，避免提前植入认知框架。）

**跨策略补充探针**（在引导题之后，各策略探针之前）：
- 当机器人直接问你"一类物体通常怎么整理"时，你觉得是在帮助你表达偏好，还是增加负担？
- 当机器人根据你的回答提出规则假设让你确认时，你觉得有帮助，还是觉得它猜得太多？

*TO（Task-Only）*
1. 逐个询问物体位置让你感觉如何？
2. 这种方式是否让你觉得清楚、可控？
3. 它是否显得重复、机械，或者效率低？
4. 你觉得这种方式能不能帮助机器人学到你的整体整理习惯？

*UL（User-Led）*
1. 当机器人问你"一类物体通常怎么整理"时，你觉得容易回答吗？
2. 这种问题有没有帮助你说出自己的整理规则？
3. 有没有时候你其实没有明确规则，或者觉得问题太抽象？
4. 这种方式是否让你觉得机器人更能理解你的偏好？

*LL（Learner-Led）*
1. 当机器人根据前面的回答提出规则假设时，你感觉如何？
2. 这种方式让你觉得机器人更聪明，还是更容易猜错？
