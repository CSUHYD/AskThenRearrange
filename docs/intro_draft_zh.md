## 正文

### 第一段：研究背景——家庭整理需要学习个性化偏好

随着家用服务机器人逐渐进入日常生活，如何使机器人行为适配特定用户的个人习惯与偏好，已成为 HCI 与 HRI 领域的重要问题。家庭整理是这一问题的典型场景：同样一批物品，不同用户可能根据使用频率、空间习惯、可达性、美观偏好或分类方式，将它们放置在不同位置。因此，家庭整理中的"正确放置"往往不能仅由物体属性或通用常识决定，而需要机器人通过与用户交互学习个人化的整理偏好。更进一步，机器人不应只记住当前被询问物体的位置，还需要将学到的偏好泛化到未被直接讨论的新物体。

### 第二段：动机——偏好难以直接表达，因此需要被主动引导

然而，用户偏好并不总是以清晰、显式、可一次性陈述的规则形式存在。认知科学与决策研究表明，人的偏好往往具有隐性、情境化和建构性的特点（Polanyi, 1966；Slovic, 1995）：用户可能能够判断某个摆放"是否合适"，却难以主动说出完整的规则体系；同时，偏好也会受到提问方式和具体情境的影响，在交互过程中被组织和表达出来。这意味着，简单等待用户主动告诉机器人"我的偏好是什么"并不现实。对于家庭整理机器人而言，主动提问不仅是收集缺失信息的手段，更是一种帮助用户将局部判断组织为可表达、可迁移偏好知识的脚手架机制（scaffolding；Wood et al., 1976）。

### 第三段：研究缺口——已有主动提问研究较少关注策略层面的影响

已有 HRI、主动学习和偏好学习研究已经认识到机器人主动提问的重要性，例如通过选择合适的对象、示范、标签、比较或澄清问题来提高学习效率（Cakmak & Thomaz, 2012；Sadigh et al., 2017；Biyik et al., 2019；Ren et al., 2023）。这些工作说明，机器人不应完全被动等待用户输入。然而，现有研究更多关注单次查询的对象、时机或信息增益，较少系统考察多轮对话中不同提问方式的组合与排序——即提问策略——如何影响用户表达出的偏好知识层次及其可泛化性。对于家庭整理任务而言，逐个询问"这个物体放哪里"可能主要获得物体级确认；引导用户表达"这类物品通常如何整理"则可能获得类别级偏好规则；而由机器人根据若干案例提出规则假设并请求确认，则代表另一种知识生成方式。由此产生的核心问题是：一个主动提问的家庭整理机器人，应如何组织提问策略，才能从用户交互中学习可迁移的整理偏好？

### 第四段：Formative Study——从人类提问中归纳策略

为理解这一问题，我们首先开展了一项人人交互（HHI）形成性研究，招募 28 名参与者组成 14 组对话，观察人类学习者如何通过提问学习他人的家庭整理偏好。通过对 139 个提问轮次的编码分析，我们识别出三种 turn-level questioning modes。第一，Action-Oriented（AO）问题用于解决具体物体或动作的放置决策，主要产生 object-level confirmations。第二，Preference-Eliciting（PE）问题引导用户表达类别级整理偏好，产生 user-authored preference rules。第三，Preference-Induction（PI）问题由学习者基于已有案例提出规则假设，并请用户确认或修正。进一步分析表明，这些提问模式会组成三种可区分的 dialogue-level questioning strategies：Task-Only（TO）主要依赖 AO 逐物体推进任务；User-Led（UL）主要通过 PE 引导用户表达规则；Learner-Led（LL）则先通过 AO 收集案例，再通过 PI 归纳并验证规则。

### 第五段：PrefQuest 与 Study 1——形式化并验证策略对泛化的影响

基于上述发现，我们提出 PrefQuest，一个用于家庭整理偏好学习的 proactive agent framework。PrefQuest 将 AO、PE 和 PI 形式化为可调度的提问模式，并通过 strategy controller 将它们组织为 TO、UL、LL 及其自适应组合 HYB 等对话级策略。系统使用 pattern proposer 生成具体问题，使用 preference updater 解析用户回答，并维护 structured preference state，用以区分 object-level confirmations 与 category-level preference rules。通过这一框架，我们能够在控制条件下比较不同提问策略如何影响机器人获得的偏好证据类型，以及这些证据是否支持对未直接讨论物体的泛化放置。

在 Study 1 中，我们将 TO、UL、LL 和 HYB 部署到同一 PrefQuest 框架中，在 102 个家居整理场景中比较不同提问预算下的 seen 和 unseen Preference Satisfaction Rate（PSR；其中 unseen PSR 定义为从未被直接讨论的物品中被正确整理的比例，是衡量偏好泛化能力的核心指标）。结果表明，提问策略会系统性影响偏好泛化表现。特别是，UL 在 unseen PSR 上优于逐物确认的 TO，提示由用户主动表达的类别级规则更有利于机器人泛化到未直接讨论的新物体。LL 的结果进一步提示，规则的抽象层次本身并不充分：由 agent 生成、用户验证的规则，其可迁移性可能不及由用户主动表达的规则，说明偏好知识由谁生成这一认识论来源，是影响泛化能力的重要因素。

### 第六段：Study 2——真实 HRI 中的表现与主动提问体验

仿真实验能够隔离策略变量，但真实用户并不是稳定、完整、规则化的 oracle。用户可能回答不完整、犹豫、临时修正，或对机器人主动提问的方式产生不同感受。因此，在 Study 2 中，我们进一步将 TO、UL 和 LL 部署到真实用户的人机交互中（$N = 24$），检验策略差异是否在自然用户回答下仍然影响机器人表现，并分析用户如何体验不同形式的主动提问。除客观整理表现外，我们重点测量三个主观维度：用户在教学过程中感受到的 teaching effort，用户是否认为机器人学到了可迁移整理规则的 perceived transferable understanding，以及用户对 agent 主动决定下一步提问内容这一行为的 perceived agent initiative。这一设计使我们能够考察客观泛化表现与用户主观体验之间是否一致，或是否存在解离。

## 研究问题

本文围绕三个研究问题展开：

**RQ1**（Formative Study）：当人类处于偏好学习者角色，向他人提问以获取家庭整理偏好时，会自然涌现出哪些提问模式和对话级提问策略？

**RQ2**（Study 1）：当这些人类来源的策略被形式化为 agent 提问策略时，它们是否会产生不同类型的偏好证据，并影响机器人对未直接讨论物体的泛化表现？

**RQ3**（Study 2）：在真实人机交互中，TO、UL 和 LL 是否仍然影响机器人表现？用户如何体验不同策略下的教学负担、机器人可迁移理解，以及 agent 的主动提问行为？

## 贡献

本文做出以下贡献：

**贡献一（形成性研究）**：通过人人交互形成性研究，我们识别出家庭整理偏好学习中的三种提问模式（AO、PE、PI）以及三种对话级策略（TO、UL、LL）。该分类揭示了不同策略在偏好知识来源上的差异：知识可以来自单个物体确认、用户主动表达的规则，或 agent 提出并由用户验证的规则假设。

**贡献二（系统）**：我们提出 PrefQuest，将人类来源的提问模式和策略形式化为 proactive agent 的可控提问机制。PrefQuest 通过结构化偏好状态区分物体级确认与类别级规则，从而支持对不同策略如何影响偏好证据积累和最终放置推断的系统比较。

**贡献三（实证）**：通过仿真实验和真实用户研究，我们表明提问策略会影响机器人对未直接讨论物体的偏好泛化表现；真实用户研究进一步显示，客观泛化表现与用户对教学负担、机器人理解程度和 agent 主动提问行为的主观评价之间可能并不完全同步。这一发现提示，偏好学习机器人不仅需要优化学习效果，也需要考虑用户如何体验 agent 的主动性。

**贡献四（设计启示）**：基于三项研究的综合发现，我们为偏好学习对话 agent 的设计者提出具体的设计启示，涵盖提问策略的选择原则、预算约束下的策略切换时机，以及如何在提升泛化效果的同时维持用户对 agent 主动性的积极感知。这些启示将仿真与用户研究中的实证结论转化为可操作的设计建议。
