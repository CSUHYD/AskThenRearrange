## 问卷星录入说明

| 设置项 | 建议 |
|---|---|
| 问卷数量 | 建议建 **4 份独立问卷**：人口统计 + Trial1 + Trial2 + Trial3 + Session-end（Session-end 可并入 Trial3 末尾） |
| 量表类型 | Likert 7 点，设置为单选矩阵题（每行一题） |
| Part 1/2/3 重复题 | 问卷星中使用"复制页"或"复制题目组"，避免手动重输 |
| 必填设置 | 所有 TE/PTU/PQE 题目、S1–S7 设为必填；S8 补充意见设为选填 |
| 页面分隔 | 每个 Part（TE/PTU/PQE）建议单独一页，避免页面过长 |
| S1 排序题 | 问卷星有"排序题"类型，直接使用；腾讯问卷可用三道单选题替代（每道选"第 1/2/3 名是哪种方式"）|
| 匿名设置 | 关闭微信登录，开启匿名填写 |
| 数据导出 | 实验结束后导出 Excel，按参与者编号与 Latin Square 行号合并到主数据表 |
