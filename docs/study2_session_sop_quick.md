# PrefQuest Study 2 — 快速参考卡

**版本**：1.0（2026-04-25）｜完整 SOP 见 `study2_session_sop.md`  
**时长**：约 65–75 分钟｜**角色**：主实验员（PI）+ 助手

---

## 开场前

- [ ] 系统启动（后端 + 前端）、TTS / STT / 拖放自检通过
- [ ] 平板充满电，录音设备可用
- [ ] 确认当前参与者的 **Latin Square 行号** → 写下 Trial 1/2/3 的策略和场景
- [ ] 练习场景道具摆好

**参与者到达后**：
1. 签知情同意书
2. 平板填人口统计问卷（约 5 分钟）
3. 口头介绍（逐字稿见完整 SOP §1.5）

---

## 练习 Trial（固定策略 TO，不计入分析）

按正式流程走一遍 Phase 1–4，**不填任何问卷**。结束后问：**"流程清楚了吗？"**

---

## 正式 Trial × 3（每个 trial 约 15 分钟）

### Phase 1 — 场景展示（~3 min）
1. 助手：控制面板选当前 trial → **Start Scene**
2. 主实验员：摆道具，将平板（物品网格）递给参与者
3. 说：*"请先熟悉一下桌上的物品和容器，准备好告诉我。"*
4. 参与者说好后：收回平板 → 助手点 **Advance to Dialogue**

### Phase 2 — 对话（时长不定，参与者自主结束）
> ⚠️ 主实验员不干预；助手操作屏幕

每轮：**Generate Question** → TTS 播放 → 按住 STT 录音 → 松开 → 修正转录 → **Submit Answer**

参与者说"可以结束了" → 助手点 **End Dialogue**

### Phase 3 — 偏好表单（~5 min）
递平板 → 说：*"请为每件物品选择你希望它被放置的容器，按自己真实习惯来。"*  
提交后收回平板。

### Phase 4 — 问卷（~5 min）
递平板 → 说：*"请完成关于刚才对话体验的问卷。"*  
> ⚠️ **不展示预测结果**

提交后收回平板。

### Phase 5 — 预测展示（~2 min）
助手点 **Show Prediction** → 屏幕转向参与者 → 说：*"绿色是和你填的一致的，红色是不一致的。"*  
给 1–2 分钟浏览，**不展开讨论**。

**Trial 结束后**：
- Trial 1/2：助手点 **Next Trial** → 换道具（约 3 分钟）
- Trial 3：进入退出访谈

---

## 退出访谈（约 12–15 分钟）

开录音 → 再次口头确认参与者同意。

**⚠️ 全程说"方式A/B/C"，不说"TO/UL/LL"**

**必问（A + F，约 8 分钟）**

A. 整体比较
- 最喜欢哪种？为什么？
- 最不喜欢哪种？为什么？

F. 主客观对齐
- 你觉得哪种最终整理得最准？
- 最喜欢的和你觉得最准的是同一种吗？
- 更准但更费脑，你愿意用吗？

**按情况问（B / C / D / E，约 5 分钟）**

B. 教学负担：哪种最费脑？哪种最容易回答？  
C. 可迁移理解：哪种最让你觉得机器人理解了你的逻辑？  
D. 主动提问体验：机器人自主决定问什么，你感觉自然吗？  
E. 策略专项（按参与者最感兴趣的 1–2 个重点问）

---

## Session 结束

**Session-end 比较问卷**（三个 trial 全部结束后）：

> 查 Latin Square → 确认 方式A = Trial1策略 / 方式B = Trial2策略 / 方式C = Trial3策略

助手点 **Advance to Final Questionnaire** → 递平板 → 说：*"请回顾三种方式，完成最后一份问卷。"*

提交后 → 助手点 **End Session**

**数据导出**：
1. **Export Session Log** → 命名 `P{编号}_{YYYYMMDD}.jsonl` → 复制到 `logs/`
2. 保存录音 → 命名 `P{编号}_{YYYYMMDD}_interview.m4a`
3. **当日备份至加密存储**
4. 点 **Reset Session**

---

## 突发情况速查

| 情况 | 处理 |
|---|---|
| TTS 失败 | 助手口头朗读问题原文 |
| STT 严重失误（3+处）| 告知参与者重录 |
| 沉默 >20 秒 | "用你平时会怎么做来回答就好" |
| 参与者问"机器人表现好不好" | "问卷之后给你看，先填完问卷" |
| 参与者中途退出 | 停止录音，导出数据，标注 incomplete |
